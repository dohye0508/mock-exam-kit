# 시각 자료 참고 가이드

[공통 작업 지침](../AGENTS.md) · [README](../README.md)

## 사람 삽화 외의 자료도 활용하기
자료의 역할을 먼저 정한다. 대화에는 인물·말풍선, 규칙에는 공지·기록표, 순서에는 일정·재생 목록, 위치에는 지도·안내판, 사건에는 기사, 시대의 단서에는 사료·유물·건축물 등 다양한 형식을 쓴다. 같은 형식이 시험지에서 반복되지 않게 한다.
참고 기출의 내용을 그대로 옮기는 것이 아니라 자료를 제시하는 형식과 정보 배치만 참고한다.

## 참고 기출 쓰는 법
- 저장소에는 기출 원본이 없다. 어떤 기출·모의고사든 PDF나 이미지로 구해 로컬 `assets/reference/`에 넣는다(git 제외). 출처 표기나 목록은 필요 없다.
- AI는 그 문제지를 훑어 자료 형식(공지·기사·표·메신저·사물·실험 장치 등), 그림 구도, 선택지 배치를 학습하고 새 문항에 반영한다. 한 번에 모든 이미지를 모델에 입력하지 않고 필요한 문항 몇 개만 본다.
- PDF에서 문항 영역이 필요하면 해당 쪽을 렌더링해 잘라 본다. 삽화가 들어 있을 법한 문항을 골라 보려면 `python tools/find_illust.py assets/reference/<폴더> -n 32 -o output/reference-sheet`로 썸네일 시트를 만든다.
- 참고 자료가 없으면 사용자에게 모의고사를 몇 개 받아 달라고 요청한다.

## 결과를 기록할 때
각 새 자료의 요청서나 작업 기록에 다음을 남긴다.
- 대상 문항과 필요한 판단 단서
- 자료 유형과 선택 이유
- AI 그림 / 문서·코드 요소의 구분
- 최종 삽입 크기와 비워 둘 공간
- 생성 파일 경로, 검증한 내용, 남은 문제
