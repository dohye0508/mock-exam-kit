# 정답 및 해설 실측 양식

`tools/build_key.py`는 사용자가 제공한 `2026고1-10월과탐정답해설.pdf`의 지면을 실측한 양식을 사용한다. 내용만 새 시험의 메타데이터·정답·해설로 바꾼다. 다른 양식이 지정되면 이 규격을 보편 기준으로 강제하지 않는다.

## 지면 규격 (단위: PDF pt)

| 요소 | 값 |
|---|---|
| 용지 | 841 × 1190 (기존 빌더의 A4 595×842와 다름) |
| 제목 테두리 | (89.782,83.723)–(753.256,155.692), 선 1.678 |
| 시험명 | HY헤드라인M 21.3549, 기준선 y=108 |
| 정답 및 해설 | HY헤드라인M 27.234, 기준선 y=146.16 |
| 세 단 시작 x | 87.84 / 314.64 / 541.32 |
| 각 단 본문 폭 | 209.37 (기존215.04에서 오른쪽5.67pt, 약2mm 여백 추가) |
| 단 구분선 | x=307.224 / 533.656, y=169.966–1068.493, 선 0.36 |
| 본문 | 한컴 바탕(Haansoft Batang, HBATANG.TTF) 8.76, 행간 13.54 |
| 본문 왼쪽 들여쓰기 | 9.96 |
| 문항 제목 | 같은 바탕 8.647, 윤곽선으로 굵게 표시 |
| 영역 표시 | HY헤드라인M 14.5049, y=201.872; 위·아래 이중선 |
| 과목명 | HY신명조 계열 H2MJRE 13.545, y=231.753 |

본문은 같은 글꼴·행간·폭으로 재조판한다. 글 내용이 다르므로 줄바꿈과 쪽수는 원본과 동일할 수 없다. 제목이 단 끝에 홀로 남지 않도록 최소 본문 공간을 확보한다. 원본의 발행자 저작권 안내문은 복사하지 않는다. 2026-11-01 사용자 수정에 따라 그 자리의 빈 공간도 제거하고, 과목명·정답표·첫 해설을 함께 62pt 위로 당긴다. 영역 아래 이중선의 끝 y=208.829에서 과목명 기준선까지22.924pt이며, 과목명 기준선에서 표 위쪽까지10.434pt다. 25문항 예시의 정답표는 현재 20문항에 맞게 4행으로 줄인다. 자동으로 여백 쪽을 추가하지 않는다.

## 글꼴

- Windows Fonts의 `H2HDRM.TTF`, `H2MJRE.TTF`, `H2GTRE.TTF`를 쓴다.
- 한컴 바탕은 Windows Fonts 또는 한컴 설치 폴더의 `Shared/TTF/All/HBATANG.TTF`에서 찾는다.
- 함초롬바탕(`HANBatang.ttf`)은 다른 글꼴이다. 조용히 대체하지 않고, 필요한 글꼴이 없으면 빌드를 중단한다.
- 글꼴 파일이나 참고 PDF 원본을 저장소에 복사하지 않는다.

## 원문과 검사

```powershell
python tools/build_key.py '정답 및 해설.pdf' content/1교시.md content/2교시.md content/3교시.md content/4교시.md
```

- 정답의 기준은 `content/N교시.md`의 `@answer`다.
- 해설은 `content/N교시_해설.md`: `## N. [출제의도] …`, 다음 줄 `@answer N`, 빈 줄로 나눈 본문이다.
- `<b>`, `<i>`, `<sub>`, `<sup>`, `<br>` 및 작은 Markdown 표를 지원한다.
- 번호 중복·누락, 정답 불일치, 빈 해설은 경고로 넘기지 않고 출력 전에 실패한다.
- 해설은 문장 다듬기와 검산의 대상이다. 학교 구성원의 공유 상식은 유지하며, 형식 수정 때문에 문제 조건을 고치지 않는다.
- 전달 전 모든 페이지를 렌더링하고, 문항 제목·정답표·표·아래첨자를 확대 확인한다. PDF의 실제 크기와 단 좌표, 최신 문구도 대조한다.

## 다음 작업자가 그대로 재사용할 것

- 서식을 새로 흉내 내지 말고 `tools/build_key.py`를 실행한다. 그 안의 `RIGHT_INSET`, `COLS`, `SUBJECT_BASELINE`, `GRID_TOP`, `GRID_ROW_HEIGHT`, `BODY_AFTER_GRID`가 실제 배치 기준이다.
- 오른쪽 추가 여백은 세 단 각각에 적용하며, 세로 구분선과 제목·정답표의 위치는 그대로다.
- 영역·과목명·정답표 사이에 삭제한 고지문 자리의 공백을 다시 만들지 않는다. 표의 행 수가 달라져도 첫 해설 위치는 표 아래에서 계산한다.
- [최신 지면 미리보기](explanation-layout-preview.png)와 렌더링 결과를 대조한다. 미리보기의 학교명·내용은 예시이며 새 시험에서는 메타데이터와 원문만 바꾼다.
- 재현에는 위 글꼴과 PyMuPDF가 필요하다. 다른 컴퓨터에서는 폰트 존재를 먼저 확인한다. 지침을 읽기만 하고 별도 렌더러로 재작성하면 같은 서식이 보장되지 않는다.
