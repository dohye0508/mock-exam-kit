# 교시별 표지: HWP 원본을 직접 사용하는 양식

기준은 사용자가 제공한 `2017학년도 대학수학능력시험 문제지V2.hwp`다. 글꼴과 도형을 비슷하게 다시 그리지 않는다. `tools/build_cover.py`가 원본에서 변환한 HWPX의 텍스트만 교체하고, 삭제 요청한 홀수형 도형을 제거한다.

## 원본과 실행

- `templates/covers/csat-2017-v2-source.hwp`: 받은 원본, 수정하지 않는다.
- `templates/covers/csat-2017-v2-source.hwpx`: 한글에서 원본을 HWPX로 저장한 것. 빌더의 입력이다.
- `templates/covers/csat-2017-v2-source.pdf`: 받은 PDF, 육안 비교용이다.
- 원본은 작은 템플릿이므로 일반 Git 대상이다. 글꼴 파일은 복사하지 않는다. 생성 PDF/HWP는 빌드 산출물이며 위 원본들과 구분한다.

```powershell
# 표지 네 장: 편집 가능한 HWPX/HWP, 개별 PDF, 표지 합본 PDF
python tools/build_cover.py output/covers

# 특정 교시만
python tools/build_cover.py output/covers content/2교시.md

# 한글이 없는 환경: 원본 서식을 가진 HWPX까지만 생성
python tools/build_cover.py output/covers --no-convert content/2교시.md

# 정식 배포: 각 교시 본문 바로 앞에 표지 1쪽 자동 삽입
python tools/build_final.py ishs/pdf

# 이미 변환해 둔 교시별 본문 재사용, 표지는 다시 생성
python tools/build_final.py ishs/pdf --reuse
```

`build_final.py`의 `_build/`에는 표지가 없는 교시별 본문만 둔다. `_covers/`에는 표지를 따로 만든다. 기존 합본에 다시 표지를 붙이지 않는다. 표지는 본문의 문항 쪽수에 포함하지 않는다. 표지 없이 출력해야 하는 명시적인 요청이 있으면 `--no-cover`를 쓴다. 단일 `python -m examkit build`는 여전히 본문만 만든다.

## 내용 치환 규칙

문항 MD 앞의 `year`, `exam`, `period`, `area`, `subject`를 사용한다. 원본의 가형 자리에는 해당 과목명을 넣는다. 가형·나형·홀수형·짝수형·문형 선택 안내는 남기지 않는다. 모든 문항이 객관식인 현재 양식은 5지선다형, 각 문항 답 하나, 배점 2점 또는 3점으로 안내한다. 주관식·단답형·4점 안내를 재사용하지 않는다. 다른 문항 체계라면 이 안내와 검증 코드를 함께 바꿔야 한다.

- 필적 확인 기본 문구: **지혜를 모아 지혜를 모아**. 원본 회색 상자 안에 넣는다.
- 필적 상자는 안내 영역의 가로 중앙에 놓는다. 상자 바깥 문단에도 내부 문구의 중앙 정렬 모양을 적용하고, 원본의 위치 맞춤용 앞 공백을 제거한다.
- 다른 프로젝트가 별도 문구를 요청하면 MD 메타데이터 `handwriting:`으로 지정한다.
- 발행 표시는 `issuer:`가 있으면 그 값, 없으면 `exam`이다. 원본의 한국교육과정평가원을 새 시험의 발행자로 남기지 않는다.
- 성명·수험번호 칸, 안내 상자, 하단 '시험이 시작되기 전까지 표지를 넘기지 마시오.'와 그 테두리는 원본 개체를 유지한다.
- 글이 길어져 넘치면 임의 축소·대체 글꼴로 감추지 않는다. 렌더링으로 확인하고 허용되는 문구를 줄이거나 해당 프로젝트의 서식 변경을 명시한다.

## 원본 수치와 글꼴

HWPX의 원본 용지는 **77102 × 111600 HWPUNIT**이다(1pt=100 HWPUNIT). 여백은 좌우5669, 위아래4251이다. 현재 한글 PDF 저장 결과는 **771 × 1116pt**, 첨부 PDF는 **770 × 1116pt**로 폭이 1pt 다르다. HWP 원본 수치를 보존하며, 이 차이를 이유로 도형을 다시 그리거나 가로로 늘이지 않는다.

| 요소 | 원본 문자 속성 |
|---|---|
| 학년도·시험명 | 신명 디나루 25pt |
| 영역명 | 신명 신그래픽 46pt |
| 과목명(옛 가형 자리) | 신명 신그래픽 56pt |
| 안내 본문 | 신명 중고딕 17pt |
| 필적 문구 | 신명 태고딕 17pt |
| 교시 표시 | 한양견명조 26pt |
| 하단 발행 표시 | 신명 디나루 28pt |

필적 상자의 가로 배치를 제외한 장평·자간·정렬·문단 간격·테두리 폭·상자 여백은 `header.xml`과 `section0.xml`을 그대로 사용한다. PDF에 T1/T2 같은 Type3 글꼴 이름만 있어도 글꼴 정보가 전혀 없다고 단정하지 않는다. 이 템플릿은 HWP 원본에서 실제 글꼴명을 확인했다. 한글의 HFT 글꼴이 필요한 환경이며, 다른 PC에서 자동 대체되면 같은 모양이 보장되지 않는다. 해당 PC에서 원본과 출력본을 렌더링해 확인한다.

본문 PDF와 표지의 용지가 다르면 표지를 본문 용지 안에 **종횡비를 유지하여 가운데 맞춤**한다. 본문 페이지는 변형하지 않는다. 예를 들어 595×841pt 본문에 넣을 때는 표지가 균일 축소되므로 원본 크기 출력이 필요하면 표지 전용 합본을 사용한다. 인쇄 대화상자의 '실제 크기'와 '용지에 맞춤'도 구분한다.

## 검증과 재사용

1. 원본 HWP/HWPX/PDF는 변경하지 않고 생성본을 별도 경로에 쓴다.
2. 한글 COM 변환은 저장소 잠금·하위 프로세스·시간 제한을 통해 직렬로 한다.
3. 표지가 각각 1쪽이며 교시·과목·필적 문구가 맞는지 검사한다. 삭제된 문구는 PDF 텍스트에도 남지 않아야 한다.
4. 본문 쪽수가 MD의 `pages`와 맞는지 검사한다. 표지가 이미 붙은 본문은 다시 합치지 않는다.
5. 표지 전체를 렌더링해 원본과 대조한다. 성명/수험번호 칸·안내 상자·경고문의 위치와 줄바꿈, 잘림, 글꼴 대체를 확인한다.
6. 표지만 추가한 작업은 기존 본문 전 쪽의 렌더링과 텍스트가 바뀌지 않았는지도 비교한다. 합본 책갈피는 교시별 표지를 가리킨다.

2026-11-01 반영: 인곽 프로젝트의 기존 20쪽 본문에 표지 4쪽을 추가했다. 이 수치를 다른 프로젝트의 고정 규칙으로 쓰지 않는다. 학교 구성원의 공유 상식은 유지하며 표지 작업 때문에 문제·해설의 내용을 바꾸지 않는다.
