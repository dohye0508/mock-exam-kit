# 원본 서식과 추가 배치 규칙 점검 — 2026-11-04

현재 구현은 원본 HWP 서식과 별도 배치 규칙이 섞여 있다. 한글 프로그램 없이 PDF가 생성된다는 실행 검증은 통과했지만, 이를 전체 양식의 원본 동일성 검증으로 해석하면 안 된다. 아래는 현재 Markdown 연결 코드에서 확인한 범위이며 모든 글리프와 모든 조합의 시각 검증 결과가 아니다.

| 대상 | 원본에서 읽는 부분 | 추가 구현 또는 미검증 부분 |
|---|---|---|
| 지면·머리글·글자 | 외부 엔진의 용지, 단, 여백, 제목/본문 문자·문단 스타일 | 줄바꿈·문단 재배치는 자체 구현. HFT 변환 윤곽과 한글 렌더링 전체의 픽셀 동일성은 미확인 |
| 국어·수학 표지 | 제공된 HWP의 문단·도형·글꼴·좌표 기록 | 메타데이터로 안내 문구/과목 목록 교체. 승인된 쪽수 글꼴 예외 존재. 재배치·합본 축소가 있으므로 원본 페이지 이미지와 무조건 같지 않음 |
| 자료 상자·보기 | 원본 표의 테두리·셀 여백·글자/문단 스타일 | `fit_content=True`로 원본 최소 높이 대신 내용에 맞춤. 나란히 놓을 때 폭을 줄이며 두 요소 사이에 자체 600 HWPUNIT(6pt) 간격 사용 |
| 한 줄 선택지 | 과탐 13번·사탐 12번 원본 10칸 표. 번호 칸 1391 + 내용 칸 4787 HWPUNIT | 이전 탭 배치와 임의 등분은 오류였으며 제거. 한 줄/다섯 줄 선택은 글자 수 6자 기준의 자체 규칙 |
| 일반 표·짝짓기·그림 위 글상자 | 일부 원본 글자 스타일, MD의 크기·좌표 입력 | 일반 표는 과탐에서도 사탐 선택지 글자 스타일 사용. 선 28, 가로 여백 각 200, 세로 추가 공간 300 HWPUNIT 등 자체 값. 원본 표 구조를 복제한 것이 아님 |
| 수식·한글 분수 | 원본 HancomEQN 및 본문 글꼴 | 수식 배치는 MathText. 한글 분수는 글자 크기의 1.12·2.45·1.52배 등 자체 비율. 한글 수식 배치 규칙을 가져온 것이 아님 |
| 문항·블록 간격 | 각 문단/원본 개체에 저장된 간격 | 그 위에 블록 뒤 기본 1mm, 문항 뒤 `gap × 4mm`를 추가. 이 추가값은 원본 HWP에서 추출한 규칙이 아님 |

## 코드 근거

- `examkit/_typst_engine.py`: `tokens`의 한글 분수, `source_box`, `data_table`, `overlays`, `source_artwork`, `blocks`.
- `examkit/native_math.py`: `MathTextParser`를 사용한 새 수식 배치.
- `examkit/cover.py`: 표지 문단 교체와 외부 원본 표지 엔진 호출.
- 외부 엔진 `scripts/compose.py`: `STYLE_IDS`, `page_geometry`, `source_box`, `source_example`, `source_table`.

## 확인한 선택지 오류

원본의 번호/내용 10칸 표를 문단 탭 위치로 잘못 바꾸어 첫 번호 사이 간격이 벌어졌다. 이어 단 폭을 임의 등분한 수정도 원본 재현이 아니었다. 현재는 원본 표의 모든 셀 내용을 교체하여 사용한다. 원본 PDF와 생성 PDF의 번호 위치를 대조하고, 테스트에서 원본 셀 폭 합 6178 HWPUNIT와 첫 번호 위치를 검사한다. 다른 요소까지 이 검증이 확대 적용되는 것은 아니다.

## 남은 작업 기준

추가 배치값마다 원본의 대응 문단/표/개체를 특정한 뒤 교체하고 원본 출력과 비교해야 한다. 새 문항 길이에 따라 필요한 자동 확장 규칙과 원본 서식 규칙을 구분한다. 원본 근거가 없는 값을 단순히 보기 좋게 조정하고 원본 재현으로 보고하지 않는다.
