  - 조건: "투표자가 1명 적었어도, 찬성이 1표 적었어도 낙선". 이것으로 투표자 수와 찬성 수 ㉠㉡을 정한다. 2026 부회장 단독 후보라는 실제 상황과 이어진다. 3점.
- B안: 개표 중간 득표(후보 3명, 남은 표 n)를 준다. "남은 표가 어떻게 나뉘어도 당선이 확정되는 최소 추가 득표"를 구한다(최악의 경우). 3점.
- 추천: A — 실제 조항과 실제 사례를 쓰고, 4·20번의 비율 계산과 다른 '경계값' 추론이다.

### 4교시 20번 [요청: 갈아엎기 → 새 소재 3 가상 상황+기본권] (3점·⑤)
- 현재: 서로 무관한 다섯 사건을 날짜 순서로 놓는다. / 소재가 억지로 묶였다.
- A안: 계산과 기본권 판단을 합친 ㄱㄴㄷ.
  - 발문은 "다음은 가상의 상황이다."로 시작한다.
  - 자료 1: 교장이 32기를 입학홍보실로 불러 "다음 해부터 월~금 기숙사 휴대폰 수거"를 알린다. 근거 발언은 ㉠ 무단 이탈·배달 증가, ㉡ 다른 학교도 걷음, ㉢ 학운위 세 주체 찬성률 평균 51.9%다.
  - 자료 2: 학운위 설문 표(주체별 응답자 수·찬성률, 학생은 16% 미만).
  - 자료 3: 학생회가 국가인권위원회에 진정을 냈다(과잉금지원칙 4요소).
  - ㄱ: 응답자 전체 찬성률(가중평균)을 계산한다.
  - ㄴ: 51.9%와 교사·학부모 찬성률로 학생 찬성률을 거꾸로 구한다.
  - ㄷ: "4요소 중 하나라도 어기면 침해 → 침해의 최소성을 어겼다면 균형성은 따지지 않아도 된다"는 논리를 판단한다. 3점, 표.
- B안: 과잉금지원칙 짝짓기 (가)(나)(다).
  - (가) 일부의 잘못으로 전체를 제한함, (나) 투폰 때문에 실효성이 의문, (다) '규제 안 함 vs 전면 수거'만 제시함.
  - 각각을 문제가 되는 심사 단계(수단의 적합성·침해의 최소성·법익의 균형성)와 짝짓는다. 3점.
- 추천: A — 사용자가 강조한 ⑨(집계 편향)를 계산으로 정면에서 묻고, 기본권은 ㄷ에 논리로 엮는다. ①~⑫ 중 나머지는 발언 2~3개로만 쓴다.
- 주의
  - 인권위 결정은 단정하지 않고 '진정'까지만 쓴다.
  - 2026-1 간담회에 실제 휴대폰 반출 논의가 있었으므로, 실제 발언 인용처럼 보이지 않게 문장을 새로 쓴다.
  - 응답자 수는 가상으로 정한다. 단순 평균이 51.9%, 전체 찬성률이 정수 %가 되도록 코드로 맞춘다.
