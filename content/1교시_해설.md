## 3. [출제의도] 두 건물의 나이 관계를 방정식으로 나타내 해를 구하기
@answer 3

## 4. [출제의도] 이웃한 칸에서 들린 소리의 수로 소리가 난 곳을 추론하기
@answer 3

숫자가 적힌 칸은 (가)~(마)가 아니므로 스스로 경보를 울리지 않고, 위·아래·옆으로 맞닿은 실험실의 경보음만 들린다. 소리는 실험실마다 모두 다르므로 숫자는 맞닿은 실험실 중 경보가 울린 실험실의 수와 같다. 울린 실험실이면 1, 울리지 않았으면 0으로 두고 식을 세운다.

① 4층 오른쪽 칸(1)에 맞닿은 실험실은 (나)뿐이다. 따라서 (나) = 1이고, (나)에서 경보가 울렸다.

② 3층 오른쪽 칸(1)에 맞닿은 실험실은 (다)와 (마)이므로 (다) + (마) = 1이다.

③ 1층 칸(1)은 위쪽 2층의 (라), (마)와 맞닿으므로 (라) + (마) = 1이다. ②, ③에서 (다) = (라)이다.

④ 3층 왼쪽 칸(1)은 (가), (다), (라)와 맞닿으므로 (가) + (다) + (라) = 1이다. (다) = (라)이므로 (가) + 2×(다) = 1에서 (다) = 0, (가) = 1이고, 따라서 (라) = 0, (마) = 1이다.

따라서 경보음이 울린 실험실은 (가), (나), (마)이다. 전수 조사로 확인해도 조건을 모두 만족하는 경우는 이 하나뿐이다.

## 10. [출제의도] 최단 경로 조건과 이동 방향 조건으로 수업 순서를 추론하기

③ 따라서 가운데 세 이동(p1 → p2, p2 → p3, p3 → p4)은 내려가기만 하는 이동이 아니어야 한다. 한 줄 위에서 계속 올라가야 하므로 순서는 필즈실, 화학, 물리, 생물실험실로 정해진다.

④ 오르내린 층 수를 센다. 교실 → 필즈실 1, 필즈실 → 화학 1, 화학 → 물리 1, 물리 → 생물 1, 생물 → 교실은 실험동 1층까지 3층을 내려가고 신관 3층에서 한 층을 더 내려가므로 4이다. 합은 1+1+1+1+4 = 8이다. (다른 순서는 합이 10 또는 12가 되지만 내려가기만 한 이동이 한 번이 아니다.)

## 14. [출제의도] 넓이 조건으로 세 실의 넓이를 구하고 위치를 정하기

## 15. [출제의도] 격자 길 찾기에서 경로의 수를 조건에 따라 세기
@answer 5

위쪽 또는 오른쪽으로만 가므로 각 칸까지의 경로 수는 (아래쪽 칸의 경로 수) + (왼쪽 칸의 경로 수)로 구한다. 기숙사 칸을 1로 두고 음영 칸은 0으로 둔다. 아래쪽 줄부터 차례로 적으면 맨 아랫줄은 1, 1, 0, 0, 0, 0, 아래에서 둘째 줄은 1, 2, 2, 2, 0, 0, 셋째 줄은 1, 0, 2, 4, 4, 4, 맨 윗줄은 1, 1, 3, 7, 11, 15이다. 따라서 맑은 날 본관까지의 경로 수는 15이다.

비 오는 날은 생태공원 칸도 0으로 두고 다시 세면 셋째 줄이 1, 0, 2, 0, 0, 0, 맨 윗줄이 1, 1, 3, 3, 3, 3이 되어 경로 수는 3이다. (생태공원을 지나는 경로는 4×3 = 12개이므로 15−12 = 3으로도 확인된다.)

따라서 맑은 날의 경로 수는 비 오는 날의 15/3 = 5(배)이다.

## 18. [출제의도] 조건에서 교무실의 위치를 추론하기
@answer 2

학생용 프린터는 본관 2층과 3층에 있고, 그 두 층에 각각 학년부 교무실이 있다. ㉠(1학년부)과 ㉡(2학년부)은 본관에 있으므로 이 두 층이 ㉠, ㉡의 위치이다. 1학년부가 2학년부보다 아래층에 있으므로 ㉠은 본관 2층, ㉡은 본관 3층이다.

ㄱ. ㉡(3층)에서 계단으로 한 층 올라가면 4층이다. ㉠은 2층이므로 틀리다. (거짓)

ㄴ. 본관의 교무실은 본교무실(1층), 1학년부(2층), 2학년부(3층)로 모두 서로 다른 층에 있다. (참)

ㄷ. 3학년부는 신관에 있는데 학생용 프린터는 본관에만 있다. 따라서 같은 건물에 프린터가 있지 않다. (거짓)

따라서 옳은 것은 ㄴ이다.

## 19. [출제의도] 속력-시간 그래프에서 이동 거리와 위치 관계를 분석하기
@answer 3

갑의 위치는 0~20초에 0.05t<sup>2</sup>, 20~100초에 2t−20이고, 이후 감속하여 120초에 200m에 도착한다. 을은 1.6m/s로 일정하게 걸어 그래프에서 125초에 도착한다.

ㄱ. 갑의 이동 거리는 속력-시간 그래프 아래의 넓이 1/2×(120+80)×2 = 200(m)이다. 을도 1.6×125 = 200(m)로 같다. (참)

ㄴ. 두 사람 사이의 거리는 속력이 같아지는 순간에 극대나 극소가 된다. 이는 갑의 속력이 1.6m/s인 16초와 104초이다. 16초일 때 을은 25.6m, 갑은 12.8m이므로 차는 12.8m이고, 104초일 때 갑은 187.2m, 을은 166.4m이므로 차는 20.8m이다. 따라서 가장 먼 때는 16초가 아니라 104초이다. (거짓)

ㄷ. 20초일 때 갑은 20m, 을은 32m이다. 20초 이후 갑의 위치 2t−20이 을의 위치 1.6t와 같아지는 때는 t = 50(초)이다. 출발부터 50초까지 을이 앞서 있었으므로 그 시간은 50초이다. (참)

따라서 옳은 것은 ㄱ, ㄷ이다.

## 20. [출제의도] 집합의 포함과 배제를 이용해 이용 학생 수를 구하기
@answer 5

밴드부원은 모두 스튜디오를, 카드키를 받은 학생은 모두 AI 융합실을 이용했다. 밴드부원이거나 카드키를 받은 학생은 4+15−1 = 18(명)이고, 이들은 모두 스튜디오나 AI 융합실을 이용했다.

무한상상실 이용자 22명 중 밴드부원이거나 카드키를 받은 학생은 2+9−1 = 10(명)이므로, 나머지 22−10 = 12(명)은 밴드부원도 카드키를 받은 학생도 아니면서 무한상상실만 이용했다.

따라서 세 공간 중 한 곳 이상 이용한 학생은 18+12 = 30(명)이고, 어느 곳도 이용하지 않은 학생은 40−30 = 10(명)이다.
