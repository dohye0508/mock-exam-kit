# 과학탐구·직업탐구 원본 PDF (Git LFS)

2026-11-01 수집. **고유 PDF 3,159개, 4.256GB, 13,530쪽**. 같은 SHA-256 파일은 한 개만 저장하고 출처를 합쳤다. 편집·스캔 차이로 같은 시험의 다른 판본은 남아 있을 수 있다. 영어·기술가정은 제외했다.

## 범위

- 과학탐구: 시행 연도 1998~2026, 1,759 PDF, 2.203GB.
- 직업탐구: 시행 연도 2004~2026, 1,400 PDF, 2.053GB.

수능·평가원 6/9월 모의평가·교육청 학력평가를 포함하며 고1·고2 자료와 옛 교육과정 과목도 있다. 연도별 과목 수와 실시 월이 달라 단순한 연도×월×과목 수를 전체 분모로 삼지 않는다. 공개 목록에서 찾은 다운로드 가능한 문제지를 모은 것이며 모든 역대 시험의 완전 수집을 뜻하지 않는다. HWP만 있거나 PDF 링크가 없는 옛 회차는 포함되지 않을 수 있다.

## 찾는 방법

- [전체 원본 목록 JSONL](../catalog/archive.jsonl): 과목·시행연도·학년도·시험·학년·경로·크기·SHA-256·출처. 이미지가 필요하면 이 목록에서 해당 PDF를 골라 문항 영역을 렌더링한다.
- [출처별 시험 기록](../catalog/archive-appearances.jsonl): 같은 파일이 여러 시험 목록에 올라온 경우의 메타데이터도 보존.
- [수집 통계](../catalog/coverage.json), [실패 기록](../catalog/download-failures.json).
- [최초 대표 14개 목록](../catalog/additional-sources.json)과 [가벼운 미리보기](../examples/extended/). 전체 목록은 archive.jsonl이다.

PDF 경로: `<분야>/<과목>/<연도>/<파일>.pdf`. 수능·평가원은 학년도, 교육청은 시행 연도로 폴더를 정한다. 정확한 기준은 목록의 calendar_year와 exam_academic_year를 확인한다. 2021학년도 수능은 2020년 12월 시행이다.

1998~2001년 시행 수능 자료는 선택과목Ⅱ 발췌본이며 공통과학 전체 시험지가 아니다. 일부 옛 고1·고2 과학 합본에는 사회 영역도 함께 있다. 목록의 `month`는 출처의 시험 회차 표기를 따르는 경우가 있어 연기·조기 시행의 실제 날짜와 다를 수 있다. 합본의 포함 과목과 확인한 페이지 범위는 `contained_subjects`, `subject_page_ranges`를 참고한다. 정답표 134개는 문제지 모음에서 제외했다.

## 선택 다운로드

새 세션마다 원본 전체를 자동으로 받지 않는다. 먼저 목록만 읽고 필요한 경로만 받는다. 예:

```powershell
git lfs install --local --skip-smudge
git lfs pull --include="assets/reference/pdf/과학탐구/물리학1/2026/2026_11_물리학1.pdf" --exclude=""
```

파일 내용이 `version https://git-lfs.github.com/spec/v1`로 시작하면 아직 원본을 받지 않은 LFS 포인터다. 목록에 있는 SHA-256과 크기로 다운로드를 검증할 수 있다.

## 출처와 검증 한계

[우사기](https://usagistudy.com/exams/), [모고집](https://mogozip.com/grade/g3/vocational), [레전드스터디](https://legendstudy.com/)의 공개 목록을 이용했다. 일부 교육청 PDF는 목록이 연결하는 EBSi 공식 파일 서버에서 직접 받았으며, 그 외에는 재게시 원본이다. 개별 출처 URL을 각 기록에 보존했다. PDF 형식·열림·쪽 수와 해시를 확인했으며 모든 문항의 내용·그림을 육안 검수한 것은 아니다. 자료 형식과 출제 스타일을 참고하되 원문 속 사실을 검증 없이 학교 문제에 옮기지 않는다. 공개 열람이 자유 재배포 라이선스를 의미하지 않으며 저장소의 비공개 방침을 유지한다.
