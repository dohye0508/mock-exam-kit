# 과학탐구·직업탐구 원본 PDF (Git LFS)

2026-10-31 추가. 과탐 8과목은 **2026학년도 수능**, 직탐 6과목은 **2026학년도 6월 모의평가**다. 각 과목 1회분이며 역대 전체 시험 모음은 아니다. 영어와 기술·가정은 사용자 요청에 따라 이 저장소에 넣지 않는다.

## 구조

- `과학탐구/<과목>/2026/<시험파일>.pdf`: 8개
- `직업탐구/<과목>/2026/<시험파일>.pdf`: 6개
- [출처·SHA-256·크기 목록](../catalog/additional-sources.json)
- [대표 미리보기](../examples/extended/): 과탐 8개와 공업 일반 1개, 일반 Git의 가벼운 PNG

원본 PDF는 Git LFS다. 특정 문항 그림이 필요하면 해당 PDF만 받고 페이지 또는 문항 영역을 렌더링한다. 원본 전체를 매번 내려받지 않는다. 경로의 학년도와 실제 시행 연도는 다를 수 있다.

## 선택 다운로드

저장소 루트에서 실행한다.

```powershell
git lfs install --local --skip-smudge
git lfs pull --include="assets/reference/pdf/과학탐구/물리학1/2026/2026_11_물리학1.pdf" --exclude=""
```

원본은 평가원 출제 자료이며 과탐은 [레전드스터디](https://legendstudy.com/1700), 직탐은 [우사기](https://usagistudy.com/exams/2026-june)의 공개 재게시에서 받았다. 공식 서버 직접 다운로드로 표기하지 않는다. 공개 열람 가능하다고 자유 재배포 라이선스가 있는 것은 아니므로 기존 비공개 방침을 따른다.
